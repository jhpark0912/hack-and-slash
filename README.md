# Aragorn: Heir of Isildur — 핵앤슬래시

반지의 제왕 세계관을 배경으로 한 브라우저 3D 핵앤슬래시. 주인공은 **아라곤**, 안두릴을 들고 브리 평원에서
펠렌노르 평원까지 끝없이 밀려오는 모르도르의 군세를 베어 넘깁니다.

- **기술 스택**: TypeScript · Three.js · Vite (외부 에셋 없음 — 모델/사운드 전부 코드로 생성)
- **3D 모델**: 프리미티브를 관절 단위로 조립한 로우폴리 캐릭터 리그 + 절차적 애니메이션(걷기·3연격·회피 구르기·회전·활·슬램·시전·돌진)
- **RPG 요소**: 레벨·경험치, 4대 스탯 배분, 9개 스킬 트리(액티브 6 + 패시브 3, 각 5랭크), 장비 3슬롯 + 가방 12칸, 4등급 아이템 랜덤 생성, 골드·물약·상점, 로컬 저장/이어하기

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 산출 (정적 호스팅 가능)
npm run preview
```

## 게임 구조

### 웨이브와 존
5웨이브마다 존이 바뀌며 조명·안개·지형 소품이 바뀝니다.

1. **브리 평원** — 숲과 바위
2. **바람마루(아몬 술)** — 노을, 폐허 기둥
3. **모리아 광산** — 어둠, 거대한 기둥과 횃불
4. **헬름 협곡** — 성벽, 바위
5. **펠렌노르 평원** — 황금빛 들판, 깃발

- 매 5웨이브: **동굴 트롤** (광역 슬램, 바닥 경고 표시)
- 매 10웨이브: **나즈굴** (비명 광역 + 둔화, 순간이동)
- 매 20웨이브: **앙마르의 마술사왕** (전설 장비 확정 드롭)

적 종류: 모르도르 오크, 오크 궁수(원거리), 와르그(돌진), 우루크하이(방패), 동부인 전사, 트롤, 나즈굴, 마술사왕.
웨이브가 오를수록 체력·공격력·경험치가 스케일링됩니다.

### 스탯
| 스탯 | 효과 |
| --- | --- |
| 힘 | 공격력 |
| 민첩 | 공격속도, 치명타 확률, 이동속도 |
| 체력 | 최대 생명력, 방어(피해 감소), 생명 재생 |
| 의지 | 최대 의지력(스킬 자원), 의지 재생, 스킬 위력 |

레벨업마다 스탯 3 / 스킬 1 포인트.

### 스킬
| 키 | 스킬 | 설명 |
| --- | --- | --- |
| 1 | 안두릴 강타 | 전방 부채꼴 강타 + 넉백 |
| 2 | 순찰자의 돌진 | 무적 돌진, 경로상 피해 |
| 3 | 회오리 베기 | 1초간 회전 다단 히트 |
| 4 | 로스로리엔의 활 | 관통 화살 (랭크당 +1발) |
| 5 | 아셀라스 | 회복 + 3초 피해 감소 |
| 6 | 서쪽의 불꽃 | 궁극기: 광역 충격파, 넉백, 기절 (레벨 10) |
| — | 두네다인의 인내 | 패시브: 생명력·재생·방어 |
| — | 이실두르의 후계자 | 패시브: 공격력·치명타 |
| — | 엘레사르의 은총 | 패시브: 이동/공격속도·의지 재생·흡혈 |

### 아이템
무기 / 갑옷 / 반지 슬롯. 일반·희귀·영웅·전설 등급에 따라 접두사 수와 수치가 커지며, 전설 등급은 고유 이름(안두릴, 미스릴 갑옷, 바라히르의 반지 …)을 가집니다. 가방에서 클릭으로 장착, 판매로 골드 획득. 상점에서 물약 구매.

### 저장
웨이브 클리어·사망·일시정지 후 저장 시 `localStorage`에 진행 상황(레벨, 스탯, 스킬, 장비, 가방, 골드, 웨이브)이 기록됩니다. 사망해도 성장은 유지되며 같은 웨이브부터 재시작합니다.

## 코드 구조

```
src/
  main.ts                 진입점
  core/    Game.ts        씬·카메라·루프·상태(타이틀/플레이/일시정지/사망)·저장
           Input.ts       키보드/마우스
           Sound.ts       WebAudio 절차적 사운드
           Utils.ts
  models/  Humanoid.ts    관절형 인간형 리그 + 포즈 키프레임 애니메이션
           Quadruped.ts   와르그 사족 리그
           Factories.ts   아라곤·오크·우루크·트롤·나즈굴… 생성기
  entities/ Player.ts     이동·3연격·회피·스킬·성장·장비
            Enemy.ts      AI 상태기계 (추격/선딜/타격/후딜/기절/특수)
            EnemyTypes.ts 적 정의·웨이브 구성·스케일링
            Projectile.ts 화살·투사체
            Pickup.ts     골드·물약·아이템 드롭
  rpg/     Stats.ts Skills.ts Items.ts Save.ts
  world/   World.ts       지형·존 조명/안개·소품·충돌
  fx/      Effects.ts DamageNumbers.ts
  ui/      HUD.ts Panels.ts
  waves/   WaveManager.ts
```

콘솔에서 `game` 객체로 디버그 가능 (예: `game.player.gainXp(1000, game)`).
